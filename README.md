# Electricity Demand Forecasting Using Machine Learning ⚡

An end-to-end machine learning project that predicts future electricity demand using historical consumption data. Built with Python, Streamlit, Pandas, NumPy, Scikit-learn, and Plotly, the application provides an interactive dashboard for data exploration, model training, performance evaluation, and future demand forecasting.

### Features
- 📊 Interactive dashboard with electricity demand visualizations
- 📁 CSV dataset upload and data preprocessing
- 🤖 Multiple ML models: Linear Regression, Decision Tree, Random Forest, and Gradient Boosting
- 📈 Model evaluation using MAE, MSE, RMSE, R², and MAPE
- 🔮 Future demand forecasting for 1, 6, 12, 24, and 48 hours
- 🧠 Model insights, feature importance, and prediction analysis
- 🎨 Modern dark-themed interface with neon accents
- 🧪 Unit tests for data processing

### Tech Stack
- **Language:** Python
- **Frontend:** Streamlit, CSS, Plotly
- **Data Processing:** Pandas, NumPy
- **Machine Learning:** Scikit-learn
- **Model Persistence:** Joblib
- **Testing:** Pytest

### Getting Started
1. Clone or download this repository.
2. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python -m streamlit run app.py
   ```
4. Open the local URL displayed in your terminal.
